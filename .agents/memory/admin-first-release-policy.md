The user wants the existing administrator to use the entire music career
platform before public rollout. Admin feature entitlement must not require
buying a public subscription. Public registration and ordinary app access remain
closed by default. MFA, account ownership, payment integrity and provider
consent remain required.

**Why:** The user explicitly made private administrator use the release target;
availability to everyone can wait.

**How to apply:** Distinguish implemented features, isolated acceptance evidence,
and actual deployed outcomes. Do not infer successful delivery, settlement,
generation or recovery from an access check. Do not publish or mutate production
data without the required separate approval.
