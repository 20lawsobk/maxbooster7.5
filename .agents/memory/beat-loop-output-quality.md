## Audio
30s mono ~92kbps MP3-in-.wav clips from MaxCore Mode C (async job_id) or Mode B (sync). MaxCore (Replit-hosted) goes to sleep — cold-start wakeup latency regularly exceeds 3 min. Initial POST timeout was 180s (too short); bumped to 600s so the service has time to wake. Both Mode C and Mode B use the same timeout.

## MaxCore Sleep Pattern
MaxCore sleeps when idle. The health ping endpoint (`/api/platform/model/info`) is unreliable (times out even when audio generation works). `/api/generate/audio` can return a `job_id` in <2s when warm. Beat loop cycles have been failing entirely when MaxCore cold-starts exceed 600s — currently the main failure mode.

## Content Quality Bugs Found + Fixed

### Bug 1 — Beat description was a placeholder (FIXED)
`_createBeatRecord` was setting description to `"Auto-generated by Beat Money Loop. Trending: {genre} / {mood}."` on **both** the `beats` and `listings` rows. This text appeared verbatim in the public marketplace. Fixed: replaced with `_buildBeatDescription()` which generates real marketing copy (mood, genre, tempo, licensing info).

### Bug 2 — Ad caption leaked raw hook labels (FIXED)
`_launchCampaign` built ad captions by doing `scan.hooks.slice(0,2).join(" ")` which paste raw internal hook-type labels like `"creative process reveal storytelling narrative"` directly into the social post description. Fixed: `_buildAdCaption()` maps each hook label to a human-readable marketing sentence.

### Bug 3 — CTA was generic (FIXED)
"Listen & Buy" → "Stream & License"

### Bug 4 — Price displayed as $25.72 (FIXED)
`Math.round(price)` now used in both description and caption so pricing reads as $26 not $25.72.

### Bug 5 — audit_log → audit_logs table name mismatch (FIXED)
`server/safety/auditLogger.ts` referenced `audit_log` (no 's') in 3 SQL queries; actual Drizzle table is `audit_logs`. The `prune-audit-log` BullMQ job was failing every cycle.

### Bug 6 — ScoreCalibrator null-ref crashes (FIXED)
`state.weights.ready` accessed on potentially-null `state` (line 451) → changed to `state?.weights?.ready`. Also `state!.loss.toFixed(4)` when loss is null → guarded with null check.

## Remaining Structural Gaps (not code bugs, require credentials/decisions)

- **MaxCore sleeping**: All beat cycles fail until MaxCore wakes up. No warmup mechanism exists.
- **Social tokens all invalid**: Twitter/TikTok/YouTube expired; Facebook/Instagram invalid OAuth; LinkedIn 403; Threads unknown error. Zero posts can be dispatched regardless of beat quality.
- **QualityGate threshold 81 > achievable score ~70**: With 0 engagement history, `deriveGate()` returns 75 but VEO_QUALITY_GATE is hardcoded 81. Autopilot posts are permanently blocked without real engagement data accumulating.
- **Old template posts in DB**: `{Song Title}` / `{Artist}` unfilled tokens appear in 3876 posts from May–June 2026 — these are legacy data from older code no longer in the codebase, not a current active bug.

## What Would Convince a Producer to Buy

A beat listing needs: (1) a real title that sounds like a producer named it, not an algorithm — "Midnight Drip Type Beat" not "Empowering Indie Type Beat — 07/17"; (2) a description that sells the sound and the use case; (3) clean round pricing; (4) a preview that actually streams. The audio URL format `/api/marketplace/audio/beats/{id}/{filename}.wav` works when audio is stored correctly.
