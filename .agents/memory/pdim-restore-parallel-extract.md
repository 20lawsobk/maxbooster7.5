---
name: pdim-restore.mjs location and serial-extraction timeout risk
description: dist/pdim-restore.mjs (Extract & Boot capsule restore) is a static git-tracked file, not regenerated by build.sh/script/build.ts; extracting all capsules serially at boot risks blowing the deploy promote-step startup-probe timeout as more/larger capsules are added.
---

`dist/pdim-restore.mjs` is committed directly to git (`git ls-files` confirms it, not gitignored)
and is NOT generated by build.sh or script/build.ts — those only produce the `.pdim` capsules and
manifests it restores. Edit it in place; the edit persists across builds since nothing overwrites it.

**Why this matters:** as of 2026-08, four capsules ship (node_modules ~269MB, python_runtime ~106MB,
external/maxcore ~478MB, external/pdim ~80MB, all gzip-9). The original implementation extracted them
one at a time via `spawnSync`. On a `vm` deployment target serving HTTP, the promote step sends a
startup probe to `GET /` with a timeout; serial extraction of ~933MB compressed pushed total boot
time past that timeout, causing the build to report `status: failed` with no runtime/promote logs at
all (build phase succeeds, capsules pack fine, then nothing — check `listDeploymentBuilds` +
`getDeploymentBuild` tail, and `fetchDeploymentLogs` returns "No deployment logs found" because the
app never went live to produce runtime logs).

**How to apply:** extractions target independent directories, so they're safe to run concurrently.
Fixed by converting `restoreCapsule` to return a Promise wrapping `spawn` (not `spawnSync`) and
`Promise.all`-ing all four calls — turns total wall-clock time from the SUM of extractions into
roughly the MAX of the largest one. If this class of promote-timeout recurs after this fix, the next
lever is reducing capsule sizes (further node_modules pruning, or deferring external/maxcore extraction
until after the server binds and responds to the probe, since it's a supervised child process started
later in start.sh, not required for the initial HTTP response).
