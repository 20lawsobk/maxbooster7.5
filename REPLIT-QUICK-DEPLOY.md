## ⚡ **QUICK START** (4 Steps)

### **1. Import to Replit** (2 min)
```
1. Go to https://replit.com
2. Click "Create Repl" → "Import from GitHub"
3. Paste: https://github.com/20lawsobk/maxbooster7.5.git
4. Click "Import from GitHub"
```

### **2. Add Database** (3 min)
```
1. Get free PostgreSQL from https://neon.tech
2. Create project: "maxbooster"
3. Copy connection string
4. In Replit: Tools → Secrets
5. Add: DATABASE_URL = postgresql://user:pass@host/db?sslmode=require
```

### **3. Run Setup** (5 min)
```bash
bash setup-replit.sh
```
✅ Installs dependencies  
✅ Runs migrations (120+ tables)  
✅ Creates admin user

### **4. Launch!** (1 click)
```
Click "Run" button in Replit!
```

**Done!** 🎉 Access your app in new tab.

## 🐛 **QUICK FIXES**

**Build fails**:
```bash
rm -rf node_modules package-lock.json && npm install && npm run build
```

**Database error**:
- Check DATABASE_URL in Secrets
- Ensure `?sslmode=require` is in connection string

**Port in use**:
```bash
pkill -f node
```
