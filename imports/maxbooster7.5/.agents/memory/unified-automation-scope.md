description: The user's required shared architecture for social, ads, beat revenue, and music workflows.
---

Treat Social Media Management, Advertisement, the Beat Money-Making Process
Loop, and Automation Workflows as one fused architecture with shared logic,
orchestration, data integrity, automation, and performance guarantees.

**Why:** The user explicitly requires these four areas to operate together,
not as isolated features.

**How to apply:** Trace shared publishing, authorization, persistence, feedback,
and queue paths across all four areas. Do not equate a notification or generated
action description with a completed operation, or claim full readiness from
isolated unit tests.
