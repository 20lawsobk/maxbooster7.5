## 🚀 **QUICK START ON REPLIT**

### **1-Click Deploy** (Fastest Way)

1. **Fork this Repl** or **Import from GitHub**:
   ```
   https://github.com/20lawsobk/maxbooster7.5.git
   ```

2. **Add Secrets** (Click "Tools" → "Secrets"):
   - `DATABASE_URL` - Get free PostgreSQL from [Neon](https://neon.tech)
   - See `env.template` for full list

3. **Run Setup**:
   ```bash
   bash setup-replit.sh
   ```

4. **Click "Run"** or:
   ```bash
   npm run deploy:replit
   ```

**That's it!** 🎉 Max Booster is now live!

### **Required Secrets** (Add in Replit Secrets):

## 🛠️ **TROUBLESHOOTING**

### **Build Fails**
```bash
rm -rf node_modules package-lock.json
npm install
npm run build
```

### **Database Connection Error**
1. Check `DATABASE_URL` in Secrets
2. Verify database allows Replit IPs
3. Test connection:
   ```bash
   node -e "const {Client}=require('pg');const c=new Client({connectionString:process.env.DATABASE_URL});c.connect().then(()=>{console.log('✅ Connected');c.end()}).catch(e=>console.error('❌',e));"
   ```

### **Port Already in Use**
```bash
pkill -f node
# Then restart
```

### **Sharp Installation Error**
```bash
npm rebuild sharp
```
