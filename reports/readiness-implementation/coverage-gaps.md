## CG-2 supported artifact contract

- `/audio/:projectId`: real audible, authorized **audio** tracks; WAV, FLAC, MP3, AAC/M4A, OGG and AIFF encoding via installed FFmpeg. Clip timeline delays, duration trims, gain/fades, track mute/solo, volume/pan, lossless intermediate stems, mixdown and optional loudness normalization are implemented.
- `/audio/:projectId/stems` and audio `exportType=stems|tracks`: actual ZIP of individually rendered tracks, with actual ZIP MIME/bytes. Track-name and numbered ZIP entries supported.
- `/data` and `/analytics`: actual owned analytics records as CSV/JSON; optional validated date range, deterministic columns without owner identifiers, CSV quoting/formula-injection protection. No fabricated records when data is empty.
- Jobs/status/history/download/cancel/retry use `generic_export_jobs`. A queued job is reclaimed on polling/listing using an atomic claim; a processing job older than 30 minutes is explicitly failed, never falsely completed. Retry creates a new attempt ID so an old worker cannot commit into it. This is request-triggered recovery, **not** a newly installed autonomous queue worker.
- Artifacts go through existing `hybridStorageService.upload/read/delete(userId, ...)` (PDIM-only). Temporary render scratch is deleted; there is no disk durability fallback. Audio sources must be readable through user PDIM storage; arbitrary remote URLs/local filesystem sources are not fetched. Legacy application-storage keys need an authorized migration/bridge before those projects can export through this route.

### CG-2 precise incompleteness (not counted as fixes)

Mastered presets/DSP processing, instrument/MIDI/warp/comp rendering, active plugin chains, dither, custom naming, unbundled stems, charts, PDF/XLSX, royalties/contracts/full backup reports, invoice/tax reports, batch/bulk bundles, email notification and shared-link artifact delivery are **not implemented** here. Their remaining legacy submission paths are rejected explicitly before they reach timer simulation; rejecting them is a safety boundary, not implementation of those features. Existing synthetic handlers remain unreachable compatibility code, not the production implementation.

The codec paths other than WAV, ZIP archives, simultaneous cancellation during native encoding, maximum workload behavior, and physical artifact expiry/retention have not been acceptance-tested. Cancellation fences publication and is checked between tracks; it does not immediately kill an already-running per-track encoder. Each native encode has a ten-minute timeout. No assertion is made that all studio project representations are supported; plugin/instrument/warped/comped sources fail explicitly rather than silently rendering a different work.
